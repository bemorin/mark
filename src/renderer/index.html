Cette aide

Épinglés : l’épingle à gauche du nom du fichier ajoute le document ouvert à Fichier → Épinglés (3 maximum). Un second clic la retire.

Vues : en bas à droite, choisis éditeur, partagé ou aperçu. Raccourcis : ⌘/Ctrl + 1, 2 ou 3.

Aperçu éditable : survole un titre, un paragraphe, une liste, une citation, un tableau ou un bloc de code, puis clique sur le petit crayon qui apparaît à gauche. Valide avec ⌘/Ctrl + Entrée, ou clique ailleurs.

Réorganiser : ouvre la table des matières, puis fais glisser la poignée d’un titre. Le déplacement de toute sa section n’est appliqué qu’après validation.

Les changements non enregistrés sont copiés localement pour pouvoir être restaurés après une fermeture imprévue. Dépose un fichier .md dans la fenêtre pour le charger dans cette même fenêtre.
